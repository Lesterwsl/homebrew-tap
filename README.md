# Lesterwsl Homebrew Tap

This tap distributes `fontvault`, an interactive macOS font, Homebrew, and application-inventory backup CLI.  
此 tap 發佈 `fontvault`：互動式 macOS 字型、Homebrew 及應用程式清單備份 CLI。

```bash
brew install Lesterwsl/tap/fontvault
fontvault setup --account Lesterwsl --repo-name mac-font-backup
fontvault
```

The tap and CLI contain no fonts, passwords, tokens, SSH private keys, one-time codes, or private inventory data. The configured backup repository remains private.  
Tap 與 CLI 不包含字型、密碼、token、SSH 私密金鑰、一次性代碼或私人清單資料；實際備份 repository 仍維持私人。
